WHAT THIS REPOSITORY CARRIES, AND WHAT IT DOES NOT
--------------------------------------------------
The definition files themselves are not committed. The JSON beside this file is
a projection of them: element paths, element names and the type each is
declared as, made by scripts/element-definitions.mjs, whose docblock states the
rule. `pnpm definitions:check` fetches the files, refuses any whose SHA-256 is
not the pinned one, re-derives the projection and compares it with the committed
copy; CI runs it.
