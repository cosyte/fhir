WHAT THIS REPOSITORY CARRIES, AND WHAT IT DOES NOT
--------------------------------------------------
This repository does NOT redistribute the example documents or the packages
that carry them. `corpus/corpus.json` records each package by URL, byte count
and SHA-256, and declares each example by its path inside that package, its
byte count and its SHA-256 digest. `scripts/corpus-fetch.mjs` retrieves each
package at run time, refuses it if its byte count or digest does not match,
and refuses any extracted example whose digest does not match. The package and
the materialised examples land in `corpus/documents/`, which is git-ignored,
so no third-party document content and no package byte enters this
repository's history. The examples carry names, dates of birth and addresses
that are the Implementation Guide's own illustrations; they are read as
validation input only, and nothing from them is printed by the differential.
