WHAT THIS REPOSITORY CARRIES, AND WHAT IT DOES NOT
--------------------------------------------------
This repository does NOT redistribute the example documents. `corpus/corpus.json`
declares each document by its name within examples-json.zip, its byte count and
its SHA-256 digest, together with the archive's own SHA-256;
`scripts/corpus-fetch.mjs` retrieves the archive at run time, refuses it if the
archive digest does not match, and refuses any extracted document whose digest
does not match. The materialised documents land in `corpus/documents/`, which is
git-ignored, so no third-party document content enters this repository's history.
